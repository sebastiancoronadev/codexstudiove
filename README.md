## 📋 Project Overview

**Codex Studio VE** is the official website and professional portfolio of **Sebastián Corona**, founder and full-stack developer based in Valencia, Venezuela 🇻🇪, serving clients across **Latin America and worldwide** 🌎.

This project represents a complete **brand redesign** — the entire website has been rebuilt from the ground up with a new architecture, new sections, new user experience, and a renewed visual identity, while keeping the signature color palette that defines the Codex Studio brand.

The new version showcases expertise in **web development**, **video editing**, **Discord server configuration**, and **Minecraft server setup**, with a strong focus on technical SEO, multi-language support, and commercial conversion.

---

## 🔄 What's New in This Redesign

This is not just a visual update — it's a **full rebranding and re-architecture** of the platform:

| Area | What Changed |
|------|--------------|
| 🏗️ **Architecture** | Migrated to a modular Next.js App Router structure with clear separation between layout, sections, UI components, and data layers |
| 🎨 **User Experience** | New section flow, new animations, glassmorphism design language inspired by Apple, and a cohesive visual rhythm throughout the page |
| 🌍 **Languages** | Reduced from 4 to 3 focused languages (English, Spanish, Chinese) with better translation coverage per section |
| 🔍 **SEO** | Significantly improved technical SEO with Schema.org structured data, dynamic metadata, hreflang tags, sitemap and robots generation |
| 📄 **Legal** | New complete legal framework: Terms, Privacy Policy, and Contracting Conditions |
| 💳 **Conversion** | New contact form with country code selector, project type selector, and direct WhatsApp integration |
| 🖼️ **Visual Assets** | New brand assets, team photos, trust client logos, project images, and payment method icons |
| ⚡ **Performance** | New image optimization pipeline (AVIF/WebP), cache strategy, and package import optimization |

## 🔍 SEO

- **Metadata API** with `generateMetadata` per page

- **Hreflang tags** for ES/EN/ZH alternates

- **Automatic robots** generation via `robots.ts`
- **Canonical URLs** on every page
- **Descriptive alt text** on all images
- **AVIF/WebP** automatic image format
- **Native lazy loading**

## 🔒 Security

- **Middleware security headers:**
  - `X-Frame-Options: DENY`
  - `X-Content-Type-Options: nosniff`
  - `Referrer-Policy: strict-origin-when-cross-origin`
  - `Permissions-Policy: camera=(), microphone=(), geolocation=()`
- **Cache-Control: immutable** for static assets
- **HTTPS enforced** by Vercel
- **HTML escaping** in contact form emails
- **Rate limiting** on contact form
- **Restricted CORS**

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/sebastiancoronadev/codexstudiove.git

# Navigate to the project
cd codexstudiove

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env.local

# Start development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

```bash
git clone https://github.com/sebastiancoronadev/codexstudiove.git

# Navegar al proyecto
cd codexstudiove

# Instalar dependencias
npm install

# Configurar variables de entorno
cp .env.example .env.local

# Iniciar servidor de desarrollo
npm run dev

# Construir para producción
npm run build
```

Abrir [http://localhost:3000](http://localhost:3000) en el navegador.

## 📋 项目概述

**Codex Studio VE** 是 **Sebastián Corona** 的官方网站和专业作品集，他是位于委内瑞拉巴伦西亚的创始人和全栈开发者 🇻🇪，为**拉丁美洲及全球**客户提供服务 🌎。

本项目代表一次**完整的品牌重塑** — 整个网站从零开始重建，采用全新的架构、全新的板块、全新的用户体验和焕新的视觉识别，同时保留了定义 Codex Studio 品牌的标志性色彩方案。

新版本展示了在**网页开发**、**视频编辑**、**Discord 服务器配置**和**Minecraft 服务器搭建**方面的专业能力，并着重于技术 SEO、多语言支持和商业转化。

---

## 🔄 本次重塑的新内容

这不仅仅是视觉更新 — 这是平台的**完整品牌重塑与架构重建**：

| 领域 | 变化内容 |
|------|----------|
| 🏗️ **架构** | 迁移至 Next.js App Router 模块化结构，清晰分离布局、板块、UI 组件和数据层 |
| 🎨 **用户体验** | 新的板块流程、新动画、受 Apple 启发的玻璃拟态设计语言，以及整页一致的视觉节奏 |

| 🔍 **SEO** | 技术 SEO 显著改进，包含 Schema.org 结构化数据、动态元数据、hreflang 标签、自动生成的 sitemap 和 robots |
| 📄 **法律** | 全新完整法律框架：条款、隐私政策和合同条件 |
| 💳 **转化** | 新联系表单，含国家代码选择器、项目类型选择器和直接 WhatsApp 集成 |
| 🖼️ **视觉资产** | 新品牌资产、团队照片、信任客户 logo、项目图片和支付方式图标 |
| ⚡ **性能** | 新图像优化管道（AVIF/WebP）、缓存策略和包导入优化 |

## 🔍 SEO

- 每页使用 **Metadata API** 与 `generateMetadata`
- **Schema.org JSON-LD** 包含 Organization、Person 和 WebSite 图
- **OpenGraph + Twitter Cards** 含 1200×630 图片
- **Hreflang 标签** 支持 ES/EN/ZH 替代
- 通过 `sitemap.ts` **自动生成 sitemap**
- 通过 `robots.ts` **自动生成 robots**
- 每页 **Canonical URL**
- 所有图片含 **描述性 alt 文本**
- **AVIF/WebP** 自动图像格式
- **原生懒加载**

## 🔒 安全

- **中间件安全头部：**
  - `X-Frame-Options: DENY`
  - `X-Content-Type-Options: nosniff`
  - `Referrer-Policy: strict-origin-when-cross-origin`
  - `Permissions-Policy: camera=(), microphone=(), geolocation=()`
- 静态资源 **Cache-Control: immutable**
- Vercel **强制 HTTPS**
- 联系表单邮件 **HTML 转义**
- 联系表单 **速率限制**
- **限制 CORS**
