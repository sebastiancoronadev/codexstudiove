## 📋 Project Overview

**Codex Studio** is the professional portfolio and digital services platform of **Sebastián Corona**, a Full-Stack Developer based in Valencia, Venezuela 🇻🇪, serving clients across **Latin America and worldwide** 🌎.

This website showcases expertise in **web development**, **video editing**, **Discord server configuration**, and **Minecraft server setup**. Built with React, TypeScript, Tailwind CSS, and Three.js, it features a fully responsive design with advanced 3D animations, real-time i18n support for 4 languages, and comprehensive SEO optimization.

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/sebastiancoronadev/codexstudiove.git

# Navigate to the project
cd codexstudiove

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
